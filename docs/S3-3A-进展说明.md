## 1. 本阶段目标

搭建可运行的本地客户端骨架，打通「Electron 主进程 + preload 安全通道 + React 渲染层」三层链路，并交付最关键的**模型配置面板**（因为后续所有 AI 能力都依赖它）。

验收标准：
- 双击可启动客户端，出现完整三段式界面
- 可在界面内配置 OpenAI / Anthropic / Gemini / Ollama 四类模型并测试连通性
- 密钥加密落盘，且明文只在主进程出现
- 类型检查零错误、可产出打包产物

## 2. 技术选型确认

| 项 | 选择 | 理由 |
|---|---|---|
| 桌面壳 | **Electron 44** | Tauri 需 Rust/MSVC 工具链，本机缺失；Electron 零额外依赖 |
| 构建 | **Vite 7** + 自研 esbuild 脚本 | 不用 electron-vite，保持对主进程/preload 打包的完全控制 |
| 框架 | **React 19** + TypeScript 5.9 | — |
| 状态 | **Zustand 5** | 轻量，无需 Provider 嵌套 |
| 打包 | **electron-builder**（NSIS + 便携版） | 便携绿色版符合「双击即用」诉求 |
| 主进程打包 | esbuild → CJS | 启动快，无运行时依赖 |

实测版本：electron `44.4.5` / vite `7.3.6` / react `19.3.0` / electron-builder `26.15.3`。

> 安装踩坑：`electron` 的 postinstall 未自动下载二进制，已用国内镜像 `npmmirror.com/mirrors/electron/` 手动补齐。

### 3.3 安全通道（`app/electron/preload/index.ts`）

`contextBridge` 只暴露语义化方法，渲染层看不到 `ipcRenderer` / `require` / `process`：

```

window.dsa.config.*    配置增删改查 + 连通性测试
window.dsa.llm.*       对话 + 流式订阅 + 中断
window.dsa.exporter.*  导出目标选择 + 落盘
window.dsa.app.*       版本信息、打开外链
```

窗口安全参数：`contextIsolation: true`、`nodeIntegration: false`、`webSecurity: true`、权限请求一律拒绝。

### 5.1 启动自检机制（本轮新增）

无头环境下验证「客户端真能起来」是纯体力活，因此固化为一个可重复执行的命令：

```bash
npm run smoke    # 退出码 0 = 通过
```

实现要点：
- `scripts/smoke.mjs` 拉起 Electron，并**显式删除 `ELECTRON_RUN_AS_NODE`**——某些终端环境预设了该变量，会让 `electron.exe` 退化成纯 Node 进程，报 `app.isPackaged` 为 undefined；
- 追加 `--disable-gpu --no-sandbox` 与独立 `--user-data-dir`，规避无 GPU 环境下 GPU 进程反复崩溃导致的 `FATAL: GPU process isn't usable`；
- 主进程侧 `attachSmokeProbe()` 仅在 `SMOKE_TEST=1` 时生效，收集渲染层控制台 error、`did-fail-load`、`render-process-gone`，加载完成 1.5s 后自行退出，**生产环境零副作用**。

> 这套机制的价值：后续每次改动都可用一条命令判断「是否把客户端改崩了」，不必人工点开窗口肉眼检查。

## 6. 遇到并解决的问题

| 问题 | 处理 |
|---|---|
| Tauri 无法使用（缺 Rust/MSVC） | 改选 Electron，实测安装成功 |
| `npm install` 两个进程并发导致 `EBUSY`（争抢同一 node.exe） | 终止重复任务，串行重装 |
| electron postinstall 未下载二进制 | 用 `ELECTRON_MIRROR` 指向 npmmirror 手动补齐 |
| `vite build` 报 `Cannot find module @rollup/rollup-win32-x64-msvc` | npm optional deps 已知 bug；`npm install --no-save @rollup/rollup-win32-x64-msvc@4.63.5` 补装 |
| 工程内存在两套并行实现（上一轮 React 版渲染器 + 本轮字符串渲染器） | 统一到字符串渲染器（画布/预览/导出共用），删除 7 个遗留文件 |
| 样式双体系冲突（`app.css` 遗留壳 vs `layout.css` 新壳） | 删除 `app.css`，`main.tsx` 已无引用；类名统一到新体系 |
| `prompt-templates.ts` 模板字符串内嵌套反引号致语法错误 | 改用中文引号 |
| 冒烟测试报 `app.isPackaged` undefined | 定位为 `ELECTRON_RUN_AS_NODE=1` 干扰，脚本内显式删除 |
| 冒烟测试 GPU 进程崩溃退出 | 加 `--disable-gpu` 等软件渲染参数 |
| `.page-frame` 的 `overflow:hidden` 裁掉页码标签 | 裁切下移到内层 `.page-render` |
