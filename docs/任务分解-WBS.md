## 2. 任务明细

### T1 输出任务分解文档
- **目标**：把计划转成可执行粒度，冻结优先级与依赖
- **输入**：`docs/项目工作计划.md`
- **输出**：`docs/任务分解-WBS.md`
- **完成标准**：每项任务含目标/优先级/依赖/DoD 四要素
- **风险**：无

### T2 S1 产品分析
- **目标**：完成对标分析，沉淀可复用结论
- **输入**：Stitch 公开资料（官方站点、SDK 接口、多来源实测）
- **输出**：`analysis/` 下 6 份报告
- **完成标准**：
  - S1-1~S1-6 全部产出
  - 功能清单标注「触发条件 / 输入 / 输出 / 能力上限」四要素
  - S1-5 产出**功能取舍矩阵**，每项给出「1:1 复刻 / 适配改造 / 不实现」结论
  - S1-6 明确可复用性路径
- **风险**：Stitch 迭代快（2025.05 发布 → 2025.12 Prototype → 2026.03 Voice Canvas），信息时效性衰减
  - **应对**：报告标注信息采集时间与可信度分级（A=官方/接口级，B=实测，C=二手转述）

### T3 S2 方案设计
- **目标**：冻结技术方案，形成可施工契约
- **输出**：`docs/` 下 5 份设计文档
- **完成标准**：
  - Design JSON Schema 含完整定义 + 可运行示例
  - 组件清单 ≥ 25 个，每个含属性矩阵
  - 设计 Token 完整（色彩/字阶/间距/圆角/阴影）
  - 交互规范含布局稿 + 快捷键表 + 状态设计
- **风险**：Schema 定型后修改成本高 → 先用示例 JSON 走通渲染再冻结

### T4 S3-3A 工程骨架 + 配置面板
- **输出**：可启动客户端 + 配置面板
- **完成标准**：
  - Electron + Vite + React + TS 跑通，主进程/预加载/渲染三层就绪
  - contextIsolation 开启，IPC 走白名单
  - 三段式布局渲染正常
  - 配置面板：分步引导 → 保存 → 连通性测试返回成功
  - 密钥经 safeStorage 加密，不落明文
- **风险**：Electron 安全配置踩坑 → 严格按官方安全清单执行

### T5 S3-3B AI 生成引擎
- **输出**：生成功能 + 提示词增强器
- **完成标准**：
  - 增强器：L0-L3 分级正确；输出含 8 区块；推断项标注；意图保全校验生效
  - 适配层：OpenAI 兼容协议可用，多配置可切换
  - 编排流水线：一次调用生成多页面，页面间风格一致
  - Schema 校验 + 失败自动修复重试（≥2 次）
  - 生成过程有流式/进度反馈
  - 项目可落盘并重新打开
- **外部依赖**：用户提供可用 API（无则走 Mock 模式验证）
- **风险**：LLM 输出格式不稳 → 强校验 + 修复重试 + 降级宽松解析

### T6 S3-3C 可视化编辑器内核
- **输出**：可用编辑器
- **完成标准**：
  - 点选/框选/Shift 多选/图层树联动
  - 拖拽移动 + 8 向缩放 + 吸附 + 参考线 + 键盘微调
  - 属性面板改动即时生效，双向绑定无回环
  - Undo/Redo 覆盖全部编辑操作
  - 图层面板支持重命名/显隐/锁定/层级调整
  - **性能门槛：拖拽稳定 60fps，200 图层项目操作无明显卡顿**
- **风险（高）**：性能不达标 → transform 位移、计算节流、虚拟滚动、局部重渲染

### T7 S3-3D 多页面 + 跳转 + 变体
- **输出**：多页面管理 + 跳转配置 + 变体生成
- **完成标准**：
  - 页面增删改复制排序 + 缩略图导航
  - 画布流视图可拖拽排布，连线展示跳转
  - 元素可绑定跳转，预览模式下点击生效
  - 多屏批量编辑可用
  - 变体生成可产出 ≥3 个方案供对比
- **风险**：跳转数据需与导出联动 → 在 Schema 中预留 interactions 字段

### T8 S3-3E 导出引擎 + 打包
- **输出**：多格式导出 + 免安装绿色版
- **完成标准**：
  - PNG：单页/全页、2x、可透明背景
  - SVG：矢量保真，文本可编辑
  - HTML：单文件自包含，**跳转可点击**，浏览器直接打开
  - JSON：源文件可导出
  - electron-builder 产出绿色版 + 安装包
  - **干净环境验证：解压后双击可启动，无缺失依赖**
- **风险**：导出保真度差异 → 样式归一化 + 资源内联 + PNG 走真实渲染快照

### T9 S4 测试验收
- **输出**：`docs/测试报告.md`
- **完成标准**：
  - 四链路功能验收 100% 通过
  - 异常分支覆盖（网络失败/密钥错误/格式异常/超大图层数）
  - 性能达标（冷启动、生成耗时、拖拽帧率、大项目加载）
  - 增强器专项：L0-L3 覆盖、意图保全有效、幂等、跨模型一致
  - 无阻断性缺陷
- **风险**：无可用 API 导致生成链路无法端到端验证 → Mock 模式兜底 + 用户 API 补充验证

### T10 交付文档
- **输出**：`docs/大模型配置操作指南.md`、`docs/产品使用说明文档.md`
- **完成标准**：非技术用户照文档可完成配置并跑通全链路

## 4. 执行顺序与同步机制

```
T1 ✅ ─▶ T2 ─▶ T3 ─▶ T4 ─▶ T5 ─▶ T6 ─▶ T7 ─▶ T8 ─▶ T9 ─▶ T10
        ▲                            ▲
        └─ 阶段交付确认 ◀─────────────┘
```

**同步机制**：每完成一个任务即同步该任务的完整成果（交付物清单 + 关键结论 + 遇到的问题），确认后进入下一任务。遇阻塞立即说明，不静默降级。
