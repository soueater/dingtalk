### 六、凭据排障（**关键环境知识，下次直接照做**）

推送一度「无输出 + SIGTERM 退出」，**不是沙箱拦截**，而是凭据助手挂起：

| 现象 | 真实原因 |
|---|---|
| `git push` 卡住后被 SIGTERM，stdout/stderr 全空 | `credential.helper=helper-selector` 需要弹 GUI 选择框，非交互 shell 下挂死 |
| `git -c credential.helper= push` | 报 `Authentication failed`（此时才是「真没凭据」） |
| `git-credential-manager github login --device --no-ui` | 报 `Cannot prompt because terminal prompts have been disabled`（因为环境里 `GIT_TERMINAL_PROMPT=0`） |
| 去掉该变量后再跑，或 `winpty -Xallow-non-tty` 包一层 | 仍无输出 / `conout != INVALID_HANDLE_VALUE` 断言失败 —— **本 shell 无真实控制台，OAuth 交互走不通** |

**可用做法（已验证）**：凭据其实**已存在 Git Credential Manager 中**，只是带 `path` 查询时会挂起。

```bash
# 1) 不带 path 查询即可拿到（带 path 会触发账号解析并挂起）
printf "protocol=https\nhost=github.com\n\n" | GIT_TERMINAL_PROMPT=0 git-credential-manager get > /tmp/ghcred.txt
chmod 600 /tmp/ghcred.txt

# 2) 用「文件型一次性助手」推送 —— 令牌不进 argv、不进日志
git -c credential.helper= -c "credential.helper=!f() { cat /tmp/ghcred.txt; }; f" \
    push -u origin <branch>

# 3) 用完立即删除含令牌的临时文件
rm -f /tmp/ghcred.txt
```

- 该凭据类型为 `gho_*`（GCM 的 GitHub OAuth App 令牌），账号 `soueater`，`GET /user` 返回 200。
- 判断凭据是否有效：`curl -H "Authorization: Bearer $TOKEN" https://api.github.com/user`。
